# HITable

面向哈尔滨工业大学学生的 Android 本地课程表。支持从哈工大教务系统（jwts.hit.edu.cn）直接在校园网内读取个人课表，也支持手工添加课程。

> 非哈尔滨工业大学官方应用。本项目不会代表学校提供服务，请以学校教务通知和实际教学安排为准。

## 下载

预编译安装包见本仓库的 **Releases** 页面。安装包仅支持 **64 位 ARM** 安卓设备
（Android 8.0 / API 26 及以上），不支持 32 位设备与 x86 模拟器。

> 桌面小组件在**纯血鸿蒙（HarmonyOS NEXT）**上不可用：系统桌面不挂载安卓小组件。
> 应用本体可经「卓易通」正常安装使用。完整的安装与使用步骤见 Releases 页面的说明文档。

## 从教务系统导入

在校园网环境下（校外需先连学校 VPN），从菜单进入「从哈工大教务导入」：

1. 在应用内的网页里完成哈工大统一身份认证；
2. 点「读取课表」，应用会从教务接口拉取指定学期的课表；
3. 可在顶部下拉框切换学期，一次读取任意学期；
4. 预览确认后再导入，识别错误的单元格可以手动修正。

实现说明：登录在 WebView 内完成（应用不接触也不保存你的密码），
读取课表走教务的 `POST /kbcx/queryGrkb` 接口——比抓取网页 DOM 更稳定，
也不受页面渲染状态影响。

## 主要功能

### 课表

- 在应用内完成哈工大统一身份认证，并从教务接口读取个人课表
- 只解析课表区域中的真实课程卡片，并按星期、节次排序
- 支持手工添加课程，以及教务系统在线导入
- 支持单双周、不连续周次、多地点和一门课多个时间段
- **今日 / 本周** 左右滑动切换；**本周支持「瀑布流」与「表格」两种排布**
  （表格：横轴星期、纵轴节次，一眼看出整周空档）
- 快速切换教学周，左右箭头逐日切换，点日期回到今天
- 国家法定节假日不显示课程；调休补班日可指定目标教学周和星期
- 长按课程卡片修改，支持单日临时停课、删除确认和时间冲突检测

### 提醒

- 本地精确通知、可调提前时间、三档声音/震动模式
- 与其它课程时间冲突时自动延后
- 荣耀、华为、小米、OPPO、vivo 等国产 Android 后台设置说明

### 桌面小组件「今日课程」

- 显示**当天全部课程列表**；同一大节的多门课合并为一行
- 左侧色条三态：**进行中 = 蓝 / 未开始 = 橙（显示开课时间）/ 已结束 = 灰**，已结束自动沉底
- 顶部显示日期、教学周、当天节数；跟随系统深色模式自动切换
- 6 套小组件配色预设（含「跟随应用」）
- 可自定义背景图：**高斯模糊**、**明暗调整**，以及**相互独立**的
  **课程卡片透明度**与**文字内容透明度**

### 界面与数据

- 6 套配色 + 自定义主色/强调色；深浅模式、AMOLED 纯黑
- 卡片圆角、界面紧凑度、卡片样式与不透明度可调
- 主页背景：预设图案，或自定义图片（可调模糊与明暗）
- 顶部问候语可自定义文字与字体
- 导入前差异统计、合并或替换、撤销导入，以及本地 JSON 备份恢复

## 隐私说明

- 课程、学期、设置和临时停课数据保存在设备本地 SQLite 数据库中。
- 不提供账号体系、云同步、统计 SDK 或广告 SDK。
- 网络仅用于用户主动打开哈尔滨工业大学教务系统读取课表，以及检查国家法定节假日与调休安排。
- 统一认证在 WebView 中完成；应用不会把密码上传到开发者服务器。
- 清除应用数据或卸载前，建议先在“备份与恢复”中导出 JSON 备份。

更完整的说明见 [PRIVACY.md](PRIVACY.md)。

## 环境要求

- Flutter 3.47.4（stable）
- Dart 3.13.3
- Java 17
- Android SDK；最低 Android 8.0（API 26），targetSdk 34

## 本地运行

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

构建 APK：

```bash
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

构建产物位于 `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`。此安装包仅支持当前主流的 64 位 ARM 安卓设备，不支持 32 位设备或 x86 模拟器。

## 发布签名

本项目使用独立的 release 签名（`android/app/release-key.jks`），签名配置从 `android/key.properties` 读取。签名文件与 `key.properties` 均已加入 `.gitignore`，请勿提交到公开仓库。**请妥善备份 keystore 与密码**——丢失后将无法对已分发的应用做覆盖升级。

## 项目结构

```text
lib/
├── application/   # Riverpod 状态与业务协调
├── data/          # SQLite、备份和国家节假日数据
├── domain/        # 课程模型、周次规则和统一课表引擎
├── import/        # CSV、XLSX、图片及网页课表解析
├── notifications/ # 本地通知规划与调度
├── presentation/  # Flutter 页面
└── widget/        # 桌面小组件数据同步
```
